# Shared UI Context

## Scope

Reusable webapp components, shared UI package primitives, hooks, styles, and common helper utilities.

## Current Baseline

- `apps/webapp/src/components/**`
- `apps/webapp/src/lib/**`
- `apps/webapp/src/hooks/**`
- `packages/ui/**`
- `docs/global/coding-standards.md` defines feature file organization for data-table-heavy feature work.
- Check `apps/webapp/src/lib/utils.ts` before creating duplicate formatting, initials, class-name, or slug helpers.

## Load When

Load this context for shared components, data tables, dialogs, badges, hooks, UI primitives, shared styles, or common helper changes.

## Update Triggers

Update this file when design-system contracts, shared component APIs, helper ownership, table patterns, or hook behavior changes.

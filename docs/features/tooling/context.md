# Tooling Context

## Scope

Bun workspace setup, Turborepo task graph, Biome, Vitest, Lefthook, and shared TypeScript configs.

## Current Baseline

- `package.json`
- `turbo.json`
- `biome.json`
- `vitest.config.ts`
- `vitest.workspace.ts`
- `lefthook.yml`
- `tools/**`

## Load When

Load this context for package scripts, workspace layout, Turbo tasks, linting, testing, hooks, or shared TypeScript config changes.

## Update Triggers

Update this file when build/test/lint conventions, task graph behavior, workspace ownership, or recurring tooling pitfalls change.
